Quick Start Guide
How to edit and publish your website
1. Edit content
Select any section from the left sidebar. Edit the fields and click Save Draft when done. A yellow dot shows unsaved changes.
2. Publish live
Click Publish Live in the top bar. Your changes go to GitHub and the live site updates within ~60 seconds.
3. Add blog posts
Go to Blog / Insights → New Post. Fill in title, category, excerpt, upload a cover image, and write the full article.
4. First time?
Click Token in the top bar to add your GitHub Personal Access Token. Required to publish. Create one at github.com/settings/tokens.
