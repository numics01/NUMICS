Quick Guide

How to edit: Select a section from the left sidebar → edit any field → click Save Changes.

How to publish: Click Export Site ↓ → download index.html → upload to Netlify Drop.

Blog posts: Go to Blog / Insights → Add New Post → fill in the fields → Save.

Images: Click the image upload area in any section → select your file → it saves automatically.
